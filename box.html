CSS3 盒模型对比演示

📦 标准盒模型 (content-box)

特点：在标准盒模型中，元素的总宽度 = width + padding + border
width 属性只控制内容区域的宽度，padding 和 border 会额外增加元素的总尺寸。
内容区域
200×110px
标准盒模型
尺寸计算：
• 设置 width: 200px, height: 150px
• padding: 20px (上下各20px)
• border: 5px (上下各5px)
• 实际总宽度 = 200 + 20×2 + 5×2 = 250px
• 实际总高度 = 150 + 20×2 + 5×2 = 200px

🎯 怪异盒模型 (border-box)

特点：在怪异盒模型中，元素的总宽度 = width (包含padding和border)
width 属性控制的是整个盒子的宽度，padding 和 border 会从内容区域中扣除。
内容区域
150×100px
怪异盒模型
尺寸计算：
• 设置 width: 200px, height: 150px
• padding: 20px (上下各20px)
• border: 5px (上下各5px)
• 实际总宽度 = 200px (固定不变)
• 内容区域宽度 = 200 - 20×2 - 5×2 = 150px
• 内容区域高度 = 150 - 20×2 - 5×2 = 100px

📊 两种盒模型对比

特性 标准盒模型 (content-box) 怪异盒模型 (border-box)
width 包含内容 仅内容区域 内容 + padding + border
总宽度计算 width + padding + border width (固定值)
布局可预测性 较低 (容易超出预期) 较高 (尺寸固定)
适用场景 需要精确控制内容尺寸 响应式布局、网格系统
浏览器支持 所有浏览器 IE8+ 及现代浏览器

💡 最佳实践建议

推荐使用怪异盒模型的原因：
  • 更容易控制元素的总体尺寸
  • 在响应式设计中表现更好
  • 避免因为padding和border导致布局溢出
  • 更符合设计师的直觉思维
推荐的CSS重置代码：
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
